note on accuracy

LearnFRC is in beta. Lessons are AI-assisted: drafted from primary sources like the WPILib docs, the game manual and vendor sites, then reviewed for accuracy. If something looks wrong, open the lesson and suggest an edit. Every open suggestion is public on the contributions page, and every fix we make to a fact is written down in the corrections log.
